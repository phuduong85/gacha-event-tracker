Beach Cafe Festival

Start Date July 29, 2026
End Date September 30, 2026
Rewards Cores, Save Data backgrounds and stickers, Rei's Outfit, and Command Delegation Modules

Beach Cafe Festival has you collecting puzzle pieces by fulfilling seasonal missions to unlock pieces of Midsummer Night Memory photos, and earn rewards based on the number of puzzle pieces you've acquired.

Chasing the Remanants of Light

Start Date July 29, 2026
End Date September 08, 2026
Rewards Rescue Anchors, Tactical and Support Certificates, Potential Disk, Prism Lens, and Tears of God

Login daily for a total of 14 days and earn rewards!

Following the Fox's Footsteps

Start Date May 27, 2026
End Date June 17, 2026
Rewards Crystals](/games/Chaos-Zero-Nightmare/archives/561072), Prism Lens, Presents, and Stickers

Check out Hilde's story by Following the Fox's Footsteps!

Following the Fox's Footsteps Event Guide

Full-Scale Offensive Season 3

Start Date -
End Date August 19, 2026
Rewards Crystals, Prism Lens, Memory Fragment and Character Growth Materials

Face bosses from previous Great Rifts to earn points and rewards based on how far you go in battle. Plan your team, select the best combatants for each boss, and use your cards efficiently within 10 turns to conquer the Full-Scale Offensive.

Virtual Tactical Simulation - Hilde

Start Date July 29, 2026
End Date August 19, 2026
Rewards Crystals, Memory Fragment and Character Growth Materials

Virtual Tactical Simulation for combatant Hilde will be available for use during Hilde's banner duration. Play her trial stage using fixed save data to obtain rewards while also testing the new combatant.

Virtual Tactical Simulation Event Guide

Virtual Tactical Simulation - Yuki

Start Date -
End Date August 12, 2026
Rewards Crystals, Memory Fragment and Character Growth Materials

Virtual Tactical Simulation for combatant Yuki will be available for use during Yuki rerun banner duration!

Virtual Tactical Simulation Event Guide
